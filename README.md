# Projetos com ESP32 e MicroPython

Repositório dedicado aos meus estudos práticos com programação, microcontroladores e eletrônica, utilizando ESP32 e MicroPython.

## 🎯 Objetivo

Aplicar conceitos de programação por meio de projetos práticos, desenvolver meu raciocínio lógico e ampliar meus conhecimentos em desenvolvimento de software e sistemas embarcados.

## 🛠️ Tecnologias e componentes

- MicroPython
- ESP32
- Python
- LEDs e potenciômetro
- Sensor DHT22
- Display OLED SSD1306
- Comunicação I²C
- ADC e PWM

## 📂 Projetos

### 01. Controle de LED com potenciômetro
Projeto para controlar o brilho de um LED por meio da leitura analógica de um potenciômetro e do controle PWM.

### 02. Monitoramento de temperatura e umidade
Projeto de estudo para obter dados de temperatura e umidade com o sensor DHT22.

### 03. Exibição de informações em display OLED
Estudo de comunicação I²C e exibição de informações em um display OLED SSD1306.
